Qalam Urdu Studio

Desktop publishing for Urdu Nastaliq, Arabic and English. Typeset newspapers, magazines, books and documents, then print them or export to PDF and Word.

Download Open in your browser

Free for Windows, macOS, Linux and Android · Works offline · Created by Uzair Asad

Made for Urdu typesetting

Everything you need to compose pages in Nastaliq, with the page layout tools of a real DTP application.

True Nastaliq

Noto Nastaliq Urdu, Gulzar, Naskh, Ruqaa, Kufi and Quranic fonts, all bundled, with correct joining and right-to-left layout.

Urdu keyboards

Phonetic, Monotype and Muqtadira layouts, plus an on-screen keyboard. Type Urdu on any computer, no system setup needed.

Page layout

Multi-column text frames, picture boxes, tables, master pages, rulers and a snap grid, on real paper sizes.

Urdu dictionary

A built-in dictionary with meanings, synonyms and antonyms, available offline.

Open and export

Save Qalam documents (.qlm), open Word, PDF and text files, and export to PDF, Word, PNG, HTML and Unicode text.

Print-ready

Print preview and native printing, with pages that match their physical size exactly.

How it's built

One codebase gives the native apps, the web app and a single-file offline version. Each layer does what it's best at.

React + TypeScript

The editor: page canvas, text frames, ribbon, keyboards, dictionary, import and export. The same code runs everywhere.

System web engine

Draws the pages. WebView2, WebKit and Android WebView shape Nastaliq with mature text engines (DirectWrite, Core Text, HarfBuzz), which handle joining, stacking and right-to-left text correctly.

Rust (Tauri 2)

The native shell: windows, Save dialogs that write real files, native printing, file associations for .qlm documents, and a single running instance. Small installers, because it uses the web engine already on your system.

GitHub Actions

Builds every installer from this source code, signs the Android app, and publishes checksums with each release.
